# Signaler une faille de sécurité

Vous avez trouvé une faille sur le site [www.hacklab-esgi.fr](https://www.hacklab-esgi.fr) ou dans ce dépôt ? Merci de nous prévenir avant d'en parler publiquement.

## Comment nous prévenir

Écrivez à **hacklab.esgi@gmail.com**.

N'ouvrez pas d'issue publique : elle serait visible de tous avant la correction.

## Quoi nous envoyer

- La page ou le fichier concerné.
- Les étapes pour reproduire le problème.
- Ce qu'un attaquant pourrait en faire, selon vous.

## La suite

Le site est tenu par des bénévoles. Nous répondons dès que possible, corrigeons, puis vous prévenons. Si vous le souhaitez, nous vous citons dans le correctif.

## Périmètre

- Le site `www.hacklab-esgi.fr` et son code (ce dépôt).
- Le workflow qui transforme une issue en proposition d'article.

Les services tiers (GitHub, Netlify, Discord, Meetup) sont à signaler à leurs éditeurs.
